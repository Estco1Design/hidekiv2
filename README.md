# HIDEKI — доработанный проект

Сохранены исходные шрифты, монохромная палитра и editorial-подача. Основной путь клиента: главная → портфолио / пакеты → бриф → контакт студии. Это подготовленный код, не опубликованный сайт.

## Запуск

Используйте Node.js 22.18+ (для встроенной проверки API) или Node.js 24 LTS и npm.

```bash
npm ci
npm run dev
```

Production:

```bash
npm run build
npm start
```

Если после установки появляются ошибки старой сборки, остановите сервер и удалите только .next, затем соберите заново. node_modules отсутствует в архиве намеренно. Не удаляйте package.json и package-lock.json. Папка .next также не включена в архив.

## Заявки и контакты

Скопируйте .env.example в .env.local. Заполните только реальные публичные контакты NEXT_PUBLIC_CONTACT_EMAIL, NEXT_PUBLIC_TELEGRAM_URL, NEXT_PUBLIC_INSTAGRAM_URL. Адреса из первоначального шаблона убраны: их принадлежность студии не подтверждена. Пустые социальные контакты не отображаются.

Чтобы отправлять заявки в Telegram, введите на сервере TELEGRAM_BOT_TOKEN и TELEGRAM_CHAT_ID. Бот должен быть добавлен в нужный чат или пользователь должен начать с ним разговор. Не присылайте токен в публичный репозиторий и не используйте для него NEXT_PUBLIC_. После изменения публичных переменных соберите и перезапустите сайт. На хостинге задайте эти переменные в настройках проекта.

POST /api/inquiry отправляет сообщение только после явной отправки формы и согласия. Успех отображается только при подтверждении Telegram. Без конфигурации API возвращает 503, интерфейс сохраняет бриф и предлагает копирование; реального получателя пока нет. При сбое Telegram — 502; неверных данных — 400; слишком большом запросе — 413. Есть ловушка для ботов и ограничение 5 обращений на IP за 10 минут в рамках одного процесса. Для нескольких серверов/массового трафика нужен общий rate limiter на уровне хостинга; доверие к x-forwarded-for зависит от прокси хостинга. Не логируются токены и брифы.

Необходимо разместить согласованные сведения об операторе и условиях обработки персональных данных до публичного запуска формы. Текст согласия в интерфейсе объясняет передачу в Telegram и не заменяет юридические документы.

## Предложения: подтвердить перед публикацией

- Personal: от 50 000 ₽, до 2 часов, до 2 образов, 10 обработанных фотографий.
- Fashion / editorial: от 80 000 ₽, до 4 часов, до 4 образов, 20 обработанных фотографий.
- Campaign / photo + film: индивидуальная смета.

Вход от 50 000 ₽ соответствует ранее выбранному публичному позиционированию. Часы, количество материалов и editorial от 80 000 ₽ — предложенная продуктовая структура, НЕ ранее согласованные факты. Подтвердите или поправьте src/data/offers.ts. Нижняя внутренняя стоимость 35 000 ₽ не опубликована. Сроки, аренда, визажист, команда и коммерческие права согласуются отдельно.

## Где менять содержание

- src/data/offers.ts — пакеты, цены и состав.
- src/data/projects.ts — названия, реальная история и кадры портфолио.
- src/data/products.ts — чёрный лук и архивные концепты.
- src/i18n/translations.ts — основной словарь RU/EN.
- src/data/site.ts + .env.local — контакты.
- MEDIA_GUIDE.md — куда загружать изображения и видео.
- AUDIT.md — ошибки исходника, изменения, проверка и остаточные задачи.

## Проверка

```bash
npm run typecheck
npm run check:inquiry
npm run build
```

API-проверка использует имитацию Telegram, реальных сообщений не отправляет. Браузерные результаты: QA_RESULTS.json. Живая доставка Telegram не проверена: нет токена и chat ID.
